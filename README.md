# Magna Dominia Astralia wiki

The public copy of the design wiki for **Magna Dominia Astralia**, a grand-strategy space simulation in Rust.

Read it on the [Wiki tab](../../wiki). Start at [Home](../../wiki), or read the whole design as one page in [Design-Document](../../wiki/Design-Document).

The pages in `wiki/` are generated from the game's private repository on every change and mirrored to the Wiki tab by `.github/workflows/sync-wiki.yml`. Do not edit them here: the next sync overwrites them. Page sources name files in the private repository (`07 D32`, `08 §1` and so on); those files are not public.
