# Design document — Magna Dominia Astralia

This is the unified design document: the current design of every system, one page each. Each page states the rules as they stand, the owner decisions that shaped them, what is not yet built, and any place where two sources disagree. The pages summarise and cite; the exact rules stay in 01-game-design.md and the decisions in 07-open-decisions.md.

The GitHub Wiki also carries every page below joined into one document, `Design-Document`, generated by `.github/scripts/wiki_sync.py`.

## Keeping it current

A design page changes in the same commit as the decision or rule it describes. After an owner call, the spec session records the decision in `07`, updates the tracker (DESIGN.md) and the affected design page, then runs Protocol 4 over the changed files. Protocol 2 (`jeverifier wiki check .`) lists pairs of statements that may contradict each other across these pages and the source docs.
